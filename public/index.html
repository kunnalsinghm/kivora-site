GuardSee and control spend

Built · tested in simulation

Guard sits in the request path, so it does more than report. Track cost by team, model and day, then set budgets that warn at 50%, 80% and 90%, and that downgrade to a cheaper model or block the request when the limit is reached.

  • Change one base URL, or send usage to the ingest API
  • Budgets that downgrade or block, plus quarantine for a suspicious key
  • Personal data redacted and known prompt-injection phrases blocked
  • Forecasts and alerts for new models and unusual spend
  • Every request recorded once, with a safety file so a bill is never lost
  • Reconcile against your provider’s billing export, and export in FOCUS format

Frequently asked questions

How do we connect Kivora?

Point your SDK’s base URL at the Kivora proxy, or send usage events to the ingest API. Kivora Guard is built for OpenAI and Anthropic traffic, and can also track self-hosted models.

Will Kivora change anything without asking us?

Guard enforces the budgets you set. When a team crosses its limit, Guard downgrades requests to a cheaper model you have approved, or blocks them if there is nothing cheaper, and says which rule did it. A key that behaves abnormally can be slowed down (quarantined) until someone reviews it. Nothing else changes on its own. Features that act beyond budgets, such as Autopilot, are in development: you choose which actions need approval, every executed action is logged, and reversible ones can be rolled back. The one exception we plan is a circuit breaker that pauses a runaway agent immediately and logs why.

When does Kivora launch, and what will it cost?

Kivora is in pre-launch and there is no public launch date yet. Planned pricing for Guard is shown on this page and isn’t final. Request early access and we’ll contact you first.

Is Kivora SOC 2 or otherwise certified?

Kivora is pre-launch and doesn’t claim any compliance certification at this stage.

Does Kivora cover cloud or Kubernetes cost?

No. Kivora attributes AI request traffic by model, agent and team. It does not cover container or cloud-infrastructure billing.
